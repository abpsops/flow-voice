FLOW Voice — Bunker Availability Agent

Standalone voice/text agent · casual language in, real feasibility math out · not connected to the live app

How this actually works, so nothing here is a black box: Your voice is transcribed by your browser's built-in speech engine. That text goes to /api/extract-intent — a small backend function running on your own Vercel deployment, holding your own Anthropic API key securely server-side — with one job only: extract what you asked for (quantity, fuel, date, barge). The AI never computes the actual answer. The real feasibility check runs through deterministic, tested gap-logic ported verbatim from the FLOW app, using real observed transfer rates from your 140 historical BDN records. Voice recognition needs Chrome or Edge (Firefox/Safari support is limited) — use the text box below if voice doesn't start. Requires your own Anthropic API key set as a Vercel environment variable — see the README for setup.
Tap and ask — e.g. "Hey FLOW, can we do 220 MT VLSFO on 25th July?"
